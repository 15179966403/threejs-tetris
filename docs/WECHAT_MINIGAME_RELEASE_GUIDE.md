## 1. 资质与主体准入清单

### 1.1 个人主体 vs 企业主体

| 对比维度 | 个人主体小游戏 | 企业/个体工商户主体小游戏 |
| :--- | :--- | :--- |
| **版号要求 (ISBN)** | **无内购纯免费：不需要版号** | 无内购纯免费：不需要版号；若含内购充值：**必须取得国家新闻出版署游戏版号** |
| **变现模式** | 仅支持**广告变现**（微信流量主：激励视频/插屏/Banner） | 支持广告变现 + 微信支付内购道具（有版号前提） |
| **文网文 / ICP 许可证** | 不需要 | 仅做无内购广告小游戏不需要；有内购需对应增值电信资质 |
| **工信部 ICP 备案** | **必须完成**（个人实名备案，审核约 1~7 工作日） | **必须完成**（企业法定代表人/管理员实名备案） |
| **软著要求 (计算机软件著作权登记证书)** | 视微信当期类目政策：休闲益智类部分首发自审，但**强烈建议取得软著**避免侵权下架风险 | **必须提供**软著登记证书扫描件 |
| **注册成本** | 30 元/年 (微信认证费用，或免认证基础版) | 300 元/年 (企业微信认证审核服务费) |

> 💡 **建议方案**：作为 3D 休闲俄罗斯方块，推荐前期先以**个人主体**发布纯广告休闲游戏，上线跑通玩法、积累种子用户和指标后，后续如有大型赛季或商业化需求，可通过微信小游戏主体迁移流程转至企业主体。

### 1.2 计算机软件著作权登记证书 (软著)
- **申请机构**：中国版权保护中心（CPCC，官网申请 https://www.ccopyright.com.cn/）。
- **材料准备**：
  1. 软件源代码：前后各连续 30 页（共 60 页，本项目 `src/` 下各模块代码完全满足标准）。
  2. 软件设计说明书：包含封面、游戏介绍、UI 截图（开始画面、设置界面、游玩画面、结算弹窗）、玩法规则说明（30~40 页图文）。
  3. 著作权人身份证明材料。
- **办理周期**：普通自办约 30~60 个工作日；加急代理约 5~15 个工作日。

## 2. 法规合规与必要材料

### 2.1 工信部小游戏 ICP 备案（强制）
- 根据工信部 2023 年《关于开展移动互联网应用程序备案工作的通知》，小游戏必须完成 ICP 备案方可上线运营。
- **办理入口**：微信公众平台后台 -> **设置** -> **小程序备案**。
- **流程**：填写主体身份信息 -> 人脸核验实名认证 -> 填报小游戏基本信息 -> 平台初审（1~2个工作日）-> 通信管理局短信核验（24小时内核验）-> 管局终审下发备案号。

### 2.2 用户隐私保护指引协议（强制）
- 微信 2023 年 9 月起强制要求处理用户信息/剪贴板/振动/相册等能力前必须获得用户同意。
- **代码已内置**：本项目封装了 [`PrivacyManager.js`](file:///f:/ThreeJSProject/src/services/PrivacyManager.js)，全自动监听 `wx.onNeedPrivacyAuthorization`，当系统需要隐私授权时自动截流，用户确认后才解冻队列。
- **后台配置路径**：微信公众平台 -> **设置** -> **基本设置** -> **服务内容声明** -> **用户隐私保护指引**。
- 声明内容如实勾选：
  - 收集并使用剪贴板（如用于复制房间码/战绩文本）。
  - 访问设备振动模块（用于马达触觉反馈）。
  - 微信好友分享与基础信息。

### 2.3 CADPA 适龄提示规范
- 依据中国音数协游戏工委 CADPA 规范，休闲益智类游戏通常定为 **CADPA 8+（适合 8 岁及以上用户）**。
- **代码已内置**：本项目在准备界面与弹窗视图底部规范渲染了：
  ```
  💚 CADPA 适龄提示 8+ | 适合8岁及以上用户
  ```
- 游戏内不得包含暴力、血腥、赌博或诱导非理性消费的元素。

### 2.4 游戏自审自查报告
- 提交审核时，微信要求上传《小游戏自审自查报告》。
- 报告要点包括：游戏玩法说明、文化健康度核查、反沉迷系统说明（接入微信官方未成年防沉迷平台）、敏感词过滤保证。

## 3. 微信后台核心配置

### 3.1 账号创建与类目选择
1. 访问微信公众平台 (https://mp.weixin.qq.com/) 注册账号，账号类型选择**“小程序”**。
2. 完善服务类目：选择 **游戏 > 休闲游戏** 或 **游戏 > 益智游戏**。
3. 获取专属 `AppID`，替换 `minigame/project.config.json` 中的 `appid` 字段。

### 3.2 基础库最低版本设定
- 推荐在微信后台将最低基础库设置为：**2.32.3** 或以上。
- 原因：该版本全面原生支持 `WebGL1` 稳定扩展、`wx.onNeedPrivacyAuthorization` 隐私合规接口、最新双通道触控事件及高采样率音频合成。

### 3.3 域名白名单 (request / downloadFile)
- 如果游戏完全单机离线运行，无需配置服务器域名。
- 如果接入远程排行榜服务端或 CDN 音视频，需在微信后台 **开发管理** -> **开发设置** -> **服务器域名** 中配置 HTTPS 域名。

## 4. 商业化变现与流量主运营

### 4.1 流量主开通门槛
- 当游戏累计独立访问用户（UV）达到 **1,000 人**，且无严重违规记录时，微信后台即可一键开通“流量主”。

### 4.2 接入点位规划建议
1. **激励视频广告 (Rewarded Video)**：
   - 触发点 A：特技模式重力道具用尽时，观看 15~30s 广告立即赠送 **3 次重力道具**。
   - 触发点 B：游戏失败（Game Over）时，提供**“看视频复活一次，清除顶部 4 行”**。
   - 触发点 C：对局结束时，**“双倍积分结算”**，冲刺全服榜单。
2. **插屏广告 (Interstitial Ad)**：
   - 每游玩完成 3~4 局游戏回到主页时平滑展示，绝不可在玩家方块下落的紧张操作中弹出。
3. **Banner 广告**：
   - 可在主菜单底部或暂停界面底部边缘展示，预留出屏幕安全区与操作热区，避免误触。

## 5. 社交裂变与开放数据域排行榜

### 5.1 微信社交分享（已在本项目落地）
- **右上角胶囊分享**：已配置 `wx.showShareMenu`，支持直接分享给好友或微信群，以及分享到朋友圈。
- **结算卡片战绩一键分享**：Game Over 弹窗设有「📤 分享战绩给好友」按钮，点击自动带上本局最高得分与当前游玩模式（特技模式/经典模式）标题，刺激好友群内 PK。

### 5.2 开放数据域好友排行 (Open Data Context) 拓展建议
1. 在 `minigame/` 目录下创建 `openDataContext/` 子包，并在 `game.json` 声明：
   ```json
   "openDataContext": "openDataContext"
   ```
2. 主域通过 `wx.setUserCloudStorage` 上传双模式各自的得分记录：
   ```javascript
   wx.setUserCloudStorage({
     KVDataList: [
       { key: 'best_classic', value: String(classicBest) },
       { key: 'best_skill', value: String(skillBest) }
     ]
   });
   ```
3. 开放数据域接收绘制指令，通过 `wx.getFriendCloudStorage` 获取微信好友得分并使用离屏 Canvas 渲染好友头像与排名。

## 6. 技术构建与微信开发者工具提审步骤

### 6.1 本地编译生成发布包
在工程根目录下执行：
```bash
# 1. 运行自动化全套质量保障测试
npm test

# 2. 编译小游戏生产环境混淆压缩包
npm run minigame
```
编译产物将写入 `minigame/` 目录：
- `minigame/game.js`：打包后的主逻辑脚本（包含 Three.js WebGL1 渲染、双模式、音频合成系统）。
- `minigame/game.json`：屏幕方向（竖屏 portrait）与子包配置。
- `minigame/project.config.json`：项目工程与编译参数。

### 6.2 微信开发者工具导入与真机调试
1. 启动 **微信开发者工具** -> 选择 **“导入项目”**。
2. 目录选择本工程的 `minigame` 文件夹（路径：`F:/ThreeJSProject/minigame`）。
3. AppID 填入在微信公众平台申请到的小游戏 AppID。
4. 点击 **“预览 (Preview)”** -> 用手机微信扫描二维码，在真机上验证：
   - 画面刷新率（保持稳定 60 FPS）。
   - 双手/单手触控操作响应。
   - 无音频卡顿与内存泄漏。
   - 切后台与切前台自动恢复。

### 6.3 上传代码与提审
1. 开发者工具右上角点击 **“上传”**，填写版本号（如 `1.0.0`）与备注。
2. 登录 **微信公众平台** -> **版本管理** -> **开发版本**。
3. 选定刚刚上传的版本，点击 **“提交审核”**。
4. 填写审核信息：
   - 测试账号/说明（无内购单机游戏，说明为休闲益智 3D 俄罗斯方块，包含经典纯净和特技模式）。
   - 上传 3~5 张高清游戏截图。
   - 上传《自审自查报告》。
5. 审核周期通常为 **1 ~ 3 个工作日**。审核通过后，管理员点击 **“全量发布”** 即可正式全网上架！

## 7. 常见驳回原因与避坑指南

1. **未完成工信部备案即提审**：系统会直接拦截，必须先走完备案管局核验。
2. **缺少用户隐私保护协议弹窗**：调用需要授权的接口时未弹隐私协议，本项目已通过 `PrivacyManager` 完善解决。
3. **未展示适龄提示**：首屏缺少 CADPA 图标或文案，本项目首屏与准备界面的 CADPA 8+ 标示已完备。
4. **诱导分享违规**：分享按钮文案绝不可写“分享后获得复活/分享领金币”，本游戏文案为合规的“分享战绩给好友”，完全符合微信运营规则。
5. **切后台死机或黑屏**：移动端退入微信后台时若持续高频渲染可能引发系统 OOM，本项目已接入 `wx.onHide` 自动切暂停与降低渲染负荷机制。
